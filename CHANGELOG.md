# Changelog — OptiMax

Формат: [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/) ·
версіювання: [SemVer](https://semver.org/lang/uk/).

## [Unreleased]

Внутрішній інженерний аудит: якість, збірка, тести й документація. Публічної поведінки продукту не змінено.

### Added
- Гейт якості JS `tools/check-js.js` (`npm run check:js`): синтаксис, заборонені `console.log` у `src/`,
  маркери конфліктів, валідність JSON — підключено у `npm run verify` і CI.
- **Smoke-тест інтерфейсу** `npm run test:ui` (`tests/smoke/main.js`): справжній рендерер Electron
  у прихованому вікні з мок-API — ініціалізація, навігація, екрани, теми, помилки консолі.
- **11 юніт-тестів черги виконання** (`tests/runner.test.js`) на фейковому PowerShell: порядок і статуси,
  накопичення undo-записів, помилки/таймаут/відсутній результат, скасування, URI-задачі, консольні задачі, живий лог.
- Релізний архів однією командою: `npm run release` + `tools/make-release-zip.ps1` (zip + SHA256).
- `.nvmrc` (Node 22) та `engines: node >= 20`.
- Документація: покажчик `docs/README.md`, довідник `docs/REFERENCE.md`, `docs/TESTING.md`,
  `docs/SECURITY.md`, журнал рішень `docs/DECISIONS.md`, беклог `docs/TECH-DEBT.md`;
  у README — вимоги, розділ «Документація» та «Типові проблеми».

### Changed
- **UI розділено на 9 модулів** (`src/ui/js/*`) замість моноліта `src/ui/app.js` (1124 рядки); код перенесено дослівно.
- `npm run verify` об'єднує тести, цілісність UI, JS-гейт, синтаксис PowerShell і smoke-тест; CI виконує саме його.
- `core/runner.js`: залежності (`ps`, `openExternal`) інжектуються через конструктор (поведінка за замовчуванням не змінилась).

### Fixed
- **Збірка більше не містить зайвих тек**: раніше до `app.asar` потрапляли `marketing/`, `dist/` (разом із zip)
  і ярлик — 129.7 МБ замість 0.4 МБ (release 387 МБ → 258 МБ).
- Згенеровані звіти рендерів отримали фінальний перевід рядка; runtime-артефакти (`automation/data/`) — у `.gitignore`.

## [1.4.0] — 2026-10-16

### Added
- **«Порядок» v2** — папки створюються просто на робочому столі та всередині «Завантажень»;
  сортуються і файли за типами, і **ярлики програм**: офісні → «Офісні програми», решта → «Програми».
  Ярлики на папки та сайти, а також системні значки («Цей ПК», «Завантаження», Кошик) не чіпаються.
- Пісочниця `tools/test-order.js` тепер створює справжні ярлики `.lnk` і перевіряє сортування програм (45 перевірок).

### Changed
- Застосунок **повністю безкоштовний**: усі 35 задач і 4 профілі доступні кожному без ключів, тріалів і оплат.
- Структура проєкту: код перенесено в `src/` (`src/main.js`, `src/preload.js`, `src/core/`, `src/ui/`).
- Локалі: 270 ключів × 5 мов.

### Removed
- Ліцензування Free/тріал/PRO, ключі `OPTMX-…`, активація, гейтинг задач, менеджер ключів.

## [1.3.0] — 2026-10-16

### Added
- Три теми оформлення: світла (типова), сіра, чорна; перемикач у Налаштуваннях, тема зберігається.
- Кольори повністю на CSS-змінних; `color-scheme` для нативних контролів; фон вікна під тему.

## [1.2.0] — 2026-10-16

### Added
- Категорія **«Порядок»**: порядок на робочому столі та в «Завантаженнях», охайні імена файлів,
  фото та відео за роками. Кожне переміщення повертається undo-записом `filemove`.
- PRELUDE-хелпери `Get-UniquePath` і `Move-FileUndo`; підтримка `filemove` у `restore.ps1`.

## [1.1.0] — 2026-10-16

### Added
- 5 мов інтерфейсу (uk, en, pl, de, ru) з фолбеком `<locale> → en → uk → ключ`.
- Екран налаштувань, економний режим для слабких ПК (≤4 ядер або ≤6 ГБ RAM).

## [1.0.0] — 2026-10-16

### Added
- Перший реліз: 31 задача, 4 категорії, 4 профілі, черга з undo, дашборд, менеджер автозапуску.
- Portable-збірка `release\OptiMax-win32-x64\OptiMax.exe` (asar, іконка й version info вшиті).
