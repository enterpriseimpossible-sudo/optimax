# DESIGN — OptiMax

## 1. Кольори (три теми)

Теми: **світла** (типова), **сіра**, **чорна** — усі токени на CSS-змінних у `ui/styles.css`:
`:root` = світла, `body.theme-gray` / `body.theme-black` перекривають значення; `color-scheme`
перемикає нативні контроли (скролбари, випадайки). Перемикач — у Налаштуваннях (зі свотчами).

| Токен | Світла (типова) | Сіра | Чорна | Використання |

| bg | `#F4F5FA` | `#23262E` | `#0B0D12` | фон вікна |

## 2. Шрифти
`Segoe UI Variable Text`, fallback `Segoe UI`, `system-ui`. Моно: `Cascadia Mono`, `Consolas`.

## 3. Типографіка
H1 22/600 · H2 16/600 · body 13.5/400 · caption 11.5/400 (колір text-dim). Міжрядковий 1.45.

## 4. Компоненти
- **Кнопки:** primary — градієнт accent, radius 10, висота 38, hover: підняти + glow; ghost — прозора з рамкою; небезпечна — danger.
- **Картка задачі:** radius 14, border, чекбокс-світч зліва, бейджі ризику/адміна/часу, hover-підняття 2px.
- **Прогрес:** смуга 6px, градієнт accent, анімовані смуги під час роботи.
- **Статуси:** pending ● dim · running ↻ accent (пульс) · ok ✓ green · fail ✕ red · skipped ⊘ warning.
- **Тости:** праворуч знизу, 3с, картка в тоні теми з кольоровою лівою смугою.

## 5. Відступи
Шкала 4 / 8 / 16 / 24 / 32. Радіуси: 10 (кнопки/поля), 14 (картки), 20 (модалі).
