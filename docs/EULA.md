# Ліцензійна угода кінцевого користувача (EULA)

**Застосунок:** OptiMax 1.4.1 («Застосунок»)
**Розробник:** ER7 Studio
**Дата редакції:** 16 жовтня 2026 р.

Це повний текст Ліцензійної угоди. Стисла версія показується в застосунку:
«Налаштування → Про застосунок → Ліцензійна угода».

## 1. Прийняття умов

Використовуючи Застосунок (запуск, виконання задач), ви підтверджуєте,
що прочитали цю угоду і приймаєте її умови. Якщо ви не погоджуєтесь — не використовуйте Застосунок.

## 2. Безкоштовно для всіх

Застосунок надається **безкоштовно** ER7 Studio як подарунок. Усі функції — 35 задач,
4 профілі, три теми оформлення, 5 мов інтерфейсу — доступні кожному без ключів,
активацій, пробних періодів і оплат. Реєстрація не потрібна; Застосунок працює
повністю офлайн.

## 3. Обмеження

Заборонено: декомпіляція, дизасемблювання, модифікація Застосунку, зняття
чи обхід захисту, розповсюдження модифікованих копій під іншим іменем,
використання Застосунку для заподіяння шкоди третім особам.

## 4. Відмова від гарантій

Застосунок надається «ЯК Є», без явних чи неявних гарантій. Застосунок змінює
системні налаштування Windows; перед змінами створюйте точку відновлення
(Застосунок пропонує це для ризикованих задач і зберігає кожну зміну для відкату).
Автори не відповідають за пошкодження системи чи даних, спричинені використанням
Застосунку, у межах, дозволених чинним законодавством.

## 5. Відповідальність користувача

- Ви повинні мати право адміністратора на ПК, де використовується Застосунок.
- Ризиковані задачі виконуються на ваш розсуд; ознайомтесь із їхніми описами
  та рівнями риску («Безпечно» / «Уважно» / «Розширено») перед запуском.

## 6. Оновлення угоди

Нові версії угоди публікуються в цьому файлі разом із версією Застосунку.
Продовження використання Застосунку після оновлення означає згоду з новою редакцією.

## 7. Подяка

Якщо Застосунок став у пригоді — просто передайте його далі. Це подарунок:
для підтримки проєкту достатньо доброго слова.

## 8. Контакти

- Підтримка та питання — контакти в README проєкту (ER7 Studio).
