# PRD — OptiMax (оптимізатор ПК)

**Версія:** 1.4.0 · **Статус:** готово — безкоштовно для всіх (ER7 Studio) · **Запуск:** `npm start` → вікно OptiMax

## 1. Огляд продукту
OptiMax — десктопний інструмент для Windows 10/11, який очищає сміття, прискорює систему,
оптимізує мережу та виконує обслуговування — усе з одного вікна, з можливістю автоматичного
запуску всіх обраних пунктів (профілі / «виділити все»).

## 2. Проблема
Оптимізація Windows вручну — це десятки команд, розкиданих по панелях і реєстру. Користувач
не знає, що безпечно, і боїться «зламати» систему.

## 3. Цілі
- Одна кнопка: обрати профіль → «Оптимізувати» → звіт по кожному пункту.
- Кожен пункт має чекбокс, опис, рівень ризику, тривалість і потребу в адміністраторі.
- Безпека: точка відновлення, журнал дій, кнопка «Повернути зміни» (undo) для оборотних твіків.
- Живий дашборд: CPU / RAM / диски / SMART + аналіз «скільки можна звільнити».

## 4. Цільові користувачі
Адміністратори, геймери, «домашні майстри» — будь-хто на Windows, хто хоче швидший ПК
без ручного копання в системі.

## 5. Ключові фічі (MVP)
- **Каталог задач** з 5 категорій: Очищення · Порядок · Продуктивність · Мережа · Система.
- **Автоматизація:** профілі (Швидкий буст, Глибоке очищення, Ігровий, Повний), «Виділити все»,
  «Лише безпечні», «Зняти все»; послідовний запуск з прогресом і живим логом.
- **Автозапуск:** список програм із реєстру + папок автозавантаження, вмикання/вимикання одним кліком.
- **Undo:** журнал змін (реєстр, служби, плани живлення, DNS, переміщені файли) і повернення.
- **Дашборд:** живі показники, SMART-статус дисків, аналіз сміття (скільки байт звільниться).
- **Адміністратор:** банер і перезапуск із підвищенням прав (UAC).
- **Три теми оформлення:** світла (типова) / сіра / чорна — перемикач у Налаштуваннях, зберігається.
