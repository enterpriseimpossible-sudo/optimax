# Політика конфіденційності

**Застосунок:** OptiMax 1.4.0
**Дата редакції:** 16 жовтня 2026 р.

Це повний текст Політики конфіденційності. Стисла версія показується в застосунку:
«Налаштування → Про застосунок → Конфіденційність».

## 1. Коротко

OptiMax працює **повністю офлайн**. Застосунок не має телеметрії, акаунтів,
рекламних SDK і не надсилає ваших даних у мережу.

## 2. Які дані зберігаються (локально, лише на вашому ПК)

Папка даних: `%APPDATA%\OptiMax\`

- `settings.json` — налаштування інтерфейсу (мова, тема, економний режим, інтервал
  статистики, підтвердження запуску) та позначки задач.
- `restore.json` — журнал внесених змін (реєстр, служби, DNS, плани живлення,
  мережеві налаштування тощо) для функції відкату.
- `logs\optimax-*.log` — журнал виконання задач.
- `tmp\` — тимчасові файли Застосунку.

Керування: «Налаштування → Дані» — відкрити папку даних, очистити журнали,
скинути налаштування.

## 3. Ключі та активація

Застосунок безкоштовний і не має ліцензійних ключів, активації чи пробних періодів.
Нічого не потрібно вводити чи надсилати — усі функції доступні одразу.

## 4. Мережеві з'єднання

- Звичайна робота Застосунку не виконує жодних мережевих запитів.
- Системні кнопки (наприклад, «Відкрити Центр оновлення») відкривають сторінки
  Windows у **зовнішньому браузері** — лише на вашу дію.

## 5. Системні зміни

Задачі оптимізації змінюють налаштування Windows (реєстр, служби, мережа,
плани живлення) — у цьому їхня суть. Кожна зміна фіксується для відкату
і може бути повернена з екрана «Історія та повернення».

## 6. Видалення даних

- «Скинути налаштування» повертає типові значення.
- Повне видалення: закрийте Застосунок і видаліть папку `%APPDATA%\OptiMax\`.

## 7. Діти

Застосунок не призначений для самостійного використання дітьми
(потрібні права адміністратора та розуміння системних змін).

## 8. Зміни політики

Оновлення публікуються в цьому файлі. Характер обробки даних
(офлайн, без збору персональних даних) не змінюється без явного зазначення.
