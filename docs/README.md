## Швидкі команди

```powershell
npm install        # залежності (один раз)
npm start          # запуск застосунку
npm test           # юніт-тести
npm run verify     # тести + цілісність UI + JS-гейт + синтаксис PowerShell
npm run package    # portable-збірка в release/
npm run site       # локальний перегляд лендінга
```

Деталі — у відповідних документах вище. Мова документації та коментарів у коді — українська.
