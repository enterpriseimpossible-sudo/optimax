# RULES — OptiMax

## 1. Що робити / чого уникати
- Слідувати PRD / ARCHITECTURE / DESIGN; зміни — маленькими кроками.
- Кожна нова задача — окремий `.ps1` + запис у `core/tasks.js`; не дублювати логіку.
- Не чіпати файли поза каталогом задачі; жодних правок системи користувача під час розробки
  без явної команди (тести — на безпечних скриптах).
- Усі деструктивні дії — з записом undo або чітким позначенням «необоротно» + підтвердженням.

## 2. Бібліотеки
- Стек: Electron + вбудовані модулі Node (child_process, fs, os, path) + PowerShell 5.1.
- UI: без фреймворків і бандлерів; тільки стандартний HTML/CSS/JS.
- Нові залежності — лише після узгодження.

## 3. Обробка помилок
- Кожен PS-скрипт: `$ErrorActionPreference='SilentlyContinue'` + явні try/catch навколо дій;
  результат завжди через `##RESULT##`.
- Runner: non-zero exit / відсутній result / timeout → статус `failed` з причиною, черга продовжується.
- Користувачу — людське повідомлення; технічне — у `logs/`.

## 4. Обмеження
- Файл ≤ ~400 рядків; українські тексти для користувача, англійські — для коду.
- Ніяких секретів у коді. UI-тексти — тільки в `ui/` або `core/tasks.js`.
