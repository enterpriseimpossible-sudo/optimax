## Відкрито

### P1 — оновлення Electron (єдиний пункт)

**Суть.** `electron ≤ 41.10.5` (у нас 31.7.7) має 3 відкриті попередження (ASAR integrity bypass,
spoofing відповідей `executeJavaScript` через service worker, AppleScript-ін'єкція на macOS),
плюс build-time `extract-zip` (path traversal) і транзитивні moderate-залежності `@electron/get`.

**Пом'якшення (уже діють).** Немає віддаленого контенту; CSP `default-src 'none'`/`connect-src 'none'`;
service worker'и не реєструються; білий список IPC (20 каналів); `contextIsolation`; збірка лише Windows x64;
секретів у репозиторії немає.

**Чому не перемкнуто.** Оновлення ламає сумісність із машинами без VC++ runtime — це свідомий пін (ADR-002)
і саме та аудиторія, для якої продукт створено. Перевірити це в поточному середовищі неможливо (тут VC++ є).

**Готово з нашого боку (2026-10-17):**
- зібрано й локально перевірено тестову версію на **Electron 44.8.0** —
  `F:\ER7\_exp-electron44\OptiMax-1.5.0-exp-electron44-win-x64.zip` (151.5 МБ,
  SHA256 `49F3E0B0B77BCAD99D7942D7EBF0459DF530F9569DEEBDED972E7D7185098B29`);
  поряд із `OptiMax.exe` покладено `msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`;
  дашборд із живими даними рендериться коректно;
- додано `tools/bundle-vcruntime.ps1` і скрипт **`npm run package:vc`**
  (пакування + копіювання DLL у реліз) — тобто перемикання після перевірки = 2 дії.

**Що перевірити на машині без VC++ runtime:**
1. `OptiMax.exe` запускається, дашборд показує дані.
2. Профіль «Швидкий буст» — задачі виконуються, звіт формується.
3. Консольна задача (наприклад SFC) — відкривається вікно PowerShell.
4. «Історія та повернення» — журнал і відкат працюють.

**Перемикання після успіху:** підняти `electron` у `package.json` до 44.x →
`npm run package:vc` → `npm run release` → новий реліз; закрити ADR-002 новим записом.

## Свідомо не робимо (з обґрунтуванням)

1. **Підпапки в `docs/`** (`architecture/`, `development/`, `decisions/`) — за поточного обсягу
   плоский список + покажчик читаються швидше; змінимо, якщо документація зросте.
2. **`console.log` у `tools/*`** — це dev-інструменти; `check-js` забороняє його лише в коді застосунку (`src/`).
3. **WebP для `assets/icon.png` / favicon** — лишаємо PNG для максимальної сумісності.
4. **`electron` оновлення без перевірки** — див. P1: без тесту на машині без VC++ це ризик для цільової аудиторії.
