# OptiMax 1.4.0 — безкоштовний оптимізатор Windows 10/11

Перший публічний реліз **OptiMax** від **ER7 Studio**. Безкоштовний для всіх: без ключів,
тріалів і підписок — подарунок користувачам.

## Що вміє

- **35 задач у 5 категоріях** — Очищення, Порядок, Продуктивність, Мережа, Система.
- **4 профілі в один клік** — Швидкий буст, Глибоке очищення, Ігровий режим, Повна оптимізація.
- **«Порядок»** — папки створюються просто на робочому столі та всередині «Завантажень»:
  файли за типами, ярлики програм окремо (офісні → «Офісні програми»). Системні значки не чіпає.
- **Повний відкат змін** — реєстр, служби, плани живлення, DNS і переміщені файли повертаються одною кнопкою.
- **Дашборд у реальному часі** — CPU/RAM, час роботи, диски й SMART;
  аналіз «скільки можна звільнити» (лише читання).
- **Менеджер автозапуску**, живий лог, скасування черги, рівні ризику, консольні задачі (SFC/DISM/chkdsk/WinSxS).
- **3 теми** (світла, сіра, чорна) і **5 мов** інтерфейсу (укр/англ/польськ/нім/рос).
- **100% офлайн** — без телеметрії, акаунтів і мережевих запитів. Економний режим для слабких ПК.

## Встановлення

1. Завантажте `OptiMax-1.4.0-win-x64.zip` нижче.
2. Розпакуйте будь-куди (можна на флешку) — інсталятор не потрібен.
3. Запустіть `OptiMax.exe` **від імені адміністратора** (частина задач цього потребує).

**Вимоги:** Windows 10/11 (x64), PowerShell 5.1 (вбудований у систему).

## Перевірки цього релізу

- `npm test` — 25/25 юніт-тестів (каталог задач, контракти скриптів, сховище, черга виконання, локалізація).
- `npm run check:ui` — цілісність 5 словників (270 ключів × 5) і всіх `id` інтерфейсу.
- `npm run check:js` / `npm run check:ps` — синтаксис JS і 39 PowerShell-скриптів.
- `npm run test:ui` — smoke-тест інтерфейсу в Electron (приховане вікно, мок-API).
- `npm run test:order` — пісочниця «Порядку»: переміщення файлів і ярликів + undo round-trip.
- Димовий запуск зібраного `OptiMax.exe` — успішно.
