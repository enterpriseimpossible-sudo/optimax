## Що змінилося з 1.4.0 (усе всередині)

**Тести**
- **+11 юніт-тестів черги** (`tests/runner.test.js`) — завдяки seam-ін'єкції `ps`/`openExternal`;
  перевіряються статуси, undo-журнал, помилки, таймаут, скасування, URI- та консольні задачі, живий лог.
- **e2e-тест містка** (`npm run test:e2e`, 20 перевірок): справжній `preload` + IPC + ядро, прогін задач, білий список каналів.
- **Візуальні регресії** (`npm run test:visual`) — порівняння екранів із базою піксель за пікселем.
- Разом: `npm test` **25/25**, smoke **15/15**, e2e **20/20**, пісочниця «Порядку» — у CI.

**Код і структура**
- UI розділено на 9 модулів (`src/ui/js/*`) замість моноліта на 1124 рядки; код перенесено дослівно.
- `Runner` отримав ін'єкцію залежностей (поведінка за замовчуванням не змінилася).
- Dev-інструменти переведено на спільний логер `tools/lib/log.js` (тихий режим `OPTIMAX_QUIET=1`).
- `check-js` тепер забороняє «сирий» `console.*` у `src/` і `tools/`, вимагає шапки-коментарі
  й перевіряє, що файли зі скриптів `package.json` існують.

**Збірка й реліз**
- Виправлено пакування: `app.asar` **129.7 МБ → 0.40 МБ** (у asar більше не потрапляють сторонні теки).
- `npm run release` = `npm run package:vc` (пакування + VC++ DLL) + zip + SHA256.
- `npm run verify` об'єднує тести, цілісність UI, JS-гейт, синтаксис PowerShell, smoke і e2e; CI виконує саме його.

**Документація й ресурси**
- Додано `docs/README.md` (покажчик), `REFERENCE.md`, `TESTING.md`, `SECURITY.md`, `DECISIONS.md` (ADR), `TECH-DEBT.md`.
- У README — вимоги, розділ документації та «Типові проблеми».
- Зображення інтерфейсу та галерея переведено у **WebP** (−66% ваги), застарілі знімки прогонів перезнято на актуальному UI.

## Перевірка на чистій машині (без VC++ runtime)

1. Розпакувати архів і запустити `OptiMax.exe` (бажано від адміністратора).
2. Профіль «Швидкий буст» → переконатися, що задачі виконуються й формується звіт.
3. Одна консольна задача (SFC/DISM) → відкривається вікно PowerShell, черга чекає закриття.
4. «Історія та повернення» → журнал і відкат працюють.
