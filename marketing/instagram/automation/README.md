# Instagram-автоматизація OptiMax

Тут лежать робочі скрипти, якими публікувалися матеріали OptiMax в Instagram
(акаунт `er7_nike.vibe`): пости та сторіс, а також перевірки результату.

> ⚠️ **Секрети.** У теці `state/auth.json` — активна сесія Instagram (cookies).
> Це чутливі дані: не комітьте їх (`.gitignore` уже виключає `state/`) і не передавайте нікому.

## Що потрібно

- Node.js 20+ і `playwright-core` (браузер ставиться окремо: `npx playwright install chromium`).
- Файл `state/auth.json` із сесією. Оновити сесію: `node src/login.mjs` (відкриє вікно — увійдіть в Instagram).

## Скрипти

| Скрипт | Призначення |
|---|---|
| `src/login.mjs` | зберегти (оновити) сесію в `state/auth.json` |
| `src/new-post.mjs` | опублікувати допис (одне фото або теку з фото) з підписом: `node src/new-post.mjs <тека-або-файл> <caption.txt>` |
| `src/new-story.mjs` | сторіс: `node src/new-story.mjs <image.png>` (розвідка) або `IG_PUBLISH=1 node src/new-story.mjs <image.png>` |
| `src/verify-api.mjs` | перевірити пост через внутрішнє API (кількість слайдів, розміри, підпис) |
| `src/verify-post.mjs`, `verify-dom.mjs`, `verify-new-post.mjs` | перевірки через сторінку профілю/поста |
| `src/probe-*.mjs` | розвідувальні проби UI (нічого не публікують) |

Ключові знахідки, зашиті у скрипти:
- у веб-версії Instagram **кадр за замовчуванням квадратний** — треба натиснути **«Розгорнути»**, інакше фото обрізається;
- веб-версія у цій сесії **не приймає кілька фото** (карусель) і не має «Історії» — карусель і сторіс публікуються з мобільного застосунку;
- кілька файлів передаються у поле завантаження через `DataTransfer` всередині сторінки (`multiple` додається примусово).

## Матеріали

Готові зображення й тексти — на рівень вище:
`marketing/instagram/carousel/` (10 слайдів 1080×1350),
`marketing/instagram/stories/` (сторіс 1080×1920 + описи),
`marketing/instagram/captions/` (тексти постів 4 мовами).
